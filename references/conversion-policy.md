# Conversion policy

1. The user must have lawful access to the source.
2. Any2Book must not remove or bypass DRM, authentication, or paywalls.
3. Faithful mode preserves wording and order; it does not summarize, translate, or enrich.
4. Unsupported structures must produce warnings instead of disappearing silently.
5. Remote resources are not embedded by default. Provide local assets when needed.
6. Claude Code and Codex correction are opt-in and must be disclosed before extracted text is uploaded through the user's signed-in CLI.
7. AI may only return auditable corrections. Low-confidence, non-unique, image-changing, and expansive patches are rejected.
8. Temporary files are removed unless debugging is explicitly enabled.
9. Never expose credentials in logs, reports, or manifests.
